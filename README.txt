# Ezequiel Zilli Photography — site gratuito

Site estático, responsivo e sem banco de dados. Já inclui:
- portfólio com filtros automáticos;
- galeria com visualização ampliada;
- serviços;
- pacotes e valores;
- botões de WhatsApp com mensagens prontas;
- Instagram;
- versão para celular;
- logo e fotos extraídos do portfólio enviado.

## Como publicar gratuitamente

A pasta pode ser publicada em serviços de hospedagem estática gratuitos, como GitHub Pages, Netlify ou Cloudflare Pages.

Basta enviar todos os arquivos mantendo a estrutura:
- index.html
- style.css
- script.js
- images/

O site não precisa de servidor ou banco de dados.
